## 为什么选择静态站点？

传统博客（如 WordPress）需要购买服务器和数据库，不仅成本高，还需要经常维护安全性。而基于静态生成的博客具有以下巨大优势：

1. **极速加载**：无数据库查询，直接传输预渲染好的 HTML。
2. **零服务器成本**：可以免费部署到 Cloudflare Pages 或 GitHub Pages。
3. **Markdown 写作**：专注于内容创作，支持 Git 版本控制。

> [!TIP]
> 静态站点通过 CDN 节点分发，全球访问延迟极低，非常适合作为个人技术沉淀与工具库。
